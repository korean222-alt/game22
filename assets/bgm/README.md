# 배경음악

여기는 **비어 있는 것이 기본**이다. 음악은 `src/ui/sound.js` 가 음표를
데이터로 들고 WebAudio 로 연주한다 — 파일 0바이트, 첫 로딩 0초, 오프라인에서도
그대로 난다.

받아 온 음원을 쓰고 싶으면 파일을 여기 넣고 `index.json` 을 만든다:

```json
{ "dev": "tense.mp3", "boss": "final.mp3", "award": "gala.mp3", "expo": "expo.mp3" }
```

이 파일이 있으면 그때부터 받아 온 쪽이 이긴다. 없으면 404 를 한 번 먹고
조용히 절차적 트랙으로 돌아간다.

| 이름 | 언제 |
|---|---|
| `dev` | 개발 현장 1~3 공정 — 긴장되고 계속 미는 곡 |
| `boss` | 마지막 버그 보스 — 더 빠르고 조이는 곡 |
| `award` | 시상식 무대 — 넓고 느린 곡 |
| `expo` | 게임덱스 |

루프로 도니까 이음매가 깨끗한 파일이라야 한다. 60~120초면 충분하다.
받을 곳은 `docs/ASSETS.md` 4-3 절에 적어 두었다.
