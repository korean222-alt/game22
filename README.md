# 소셜게임 스토리 3D

카이로소프트의 경영 시뮬레이션 **소셜게임 스토리**(Social Dev Story)를
WebGL2 실시간 3D로 옮긴 리메이크. 의존성 없이 브라우저에서 바로 돌아간다.

> 오늘부터 사장님입니다.
> 사무실에 직원을 앉히고, 기획서를 뽑고, **아이디어와 싸워** 게임을 만들고,
> 출시해서 유저를 모으세요.

**모바일 가로 모드 전용 게임**이다. 세로로 들면 돌려달라는 안내가 뜨고,
가로에서만 플레이된다. 홈 화면에 추가하면 PWA로 설치되어 주소창 없이
전체화면으로 뜨고 오프라인에서도 돈다.

## 실행

```bash
python3 -m http.server 8080     # 또는 npx serve
# http://localhost:8080
```

ES 모듈을 쓰므로 정적 서버가 필요하다 (`file://` 로는 열리지 않는다).
빌드 스텝도, 패키지 설치도 없다. WebGL2를 지원하는 브라우저면 된다.
서비스 워커는 HTTPS 에서만 등록되므로 로컬에서는 오프라인 캐시가 꺼져 있다.

## 조작

**터치 (기본)**

| 입력 | 동작 |
|---|---|
| 한 손가락 드래그 | 카메라 회전 |
| 두 손가락 오므리기/벌리기 | 줌 |
| 두 손가락 드래그 | 시점 이동 |
| 좌상단 ☰ | 패널 열기/닫기 |
| 우측 층 버튼 | 층 이동 |
| 좌하단 ⛶ | 전체화면 |
| 좌하단 🚶 | **1인칭 모드** 들어가기/나가기 |

**1인칭 모드** — 사장이 사무실을 직접 걷는다.

| 입력 | 동작 |
|---|---|
| 화면 **왼쪽 아래**를 누른 채 끌기 | 그 자리에 조이스틱이 생기고 이동 |
| 화면 **오른쪽** 드래그 | 시점 회전 |
| 층 버튼 | 그 층으로 올라가서 계속 걷기 |

**키보드 (데스크톱)**

| 키 | 동작 |
|---|---|
| `Q` / `E` | 층 아래 / 위 |
| `1`~`7` | 회사 / 직원 / 개발 / 상점 / 도감 / 운영 / 사무실 탭 |
| `Space` | 개발 배틀 한 턴 진행 |
| `Tab` | 벽 투시 토글 |
| `F` | 1인칭 모드 토글 |
| `WASD` / 방향키 | 1인칭에서 이동 |

## 게임 루프

```
기획서 뽑기 (스태미나 -1)
   ↓  장르 · ★등급이 정해진다
플랫폼 · 수익 모델 · 개발 팀 선택
   ↓
🗣 킥오프 회의 — 배정된 팀원이 자리에서 일어나 회의실로 걸어가 의견을 낸다
   ↓
★ 개발 배틀 ★  — 아이디어 HP를 0으로
   ├ 매 턴 스태미나 소모, 팀원이 순서대로 데미지
   ├ HP 66% → 🗣 회의 → 게임 내용 아이디어 3장 중 택 1  (장르 궁합이 핵심)
   └ HP 33% → 🗣 회의 → 개발 방식 아이디어 3장 중 택 1
   ↓
완성 → 5개 품질(화제성·조작성·임팩트·소셜·지속성) + 버그 + 평론가 4인
   ↓
디버그 → 홍보 결정 → 출시 → 운영 (최대 3작품 동시, 주간 매출)
   ↓
팬 증가 → 회사 랭크 → 정원·스태미나·층 해금·플랫폼 해금
   ↓
연구 포인트 → 영구 강화 · 사무실 층 구매 · 다음 기획서
```

### 알아둘 것

- **팀 구성이 곧 품질이다.** 품질은 *1인·1턴당* 기여의 평균이다. 사람을 더
  넣으면 개발이 빨라질 뿐 품질이 오르지는 않는다. 네트워커가 없는 팀은
  소셜과 지속성이 1점에서 멈춘다.
- **의욕(Motivation)** 1당 +0.5% 배율에 크리티컬 확률까지 오른다. 자기
  기획서로 게임을 완성하면 +1.
- **기획자는 3층(기획실)에** 앉히면 기획서 등급이 오른다. 원작의
  "작가 층과 개발자 층을 분리하라"는 조언을 그대로 규칙으로 만들었다.
- **아이템 지급에는 스태미나가 든다.** 육성과 개발이 같은 자원을 놓고 다툰다.
- 평론가 합계 **32점 이상**이면 명예의 전당 → 속편 제작 해금. 잘 두면
  대략 **4~5년차**에 첫 등재가 나온다 — 핵심 인원이 두 번째 전직을 마치는 때다.
- **출시할 때마다 팀원이 경험치를 얻는다.** 아이템은 빠른 길, 출시는 느린 길.
  돈을 한 푼도 안 써도 성장이 멈추지는 않는다.
- **자금이 마이너스로 깊어지면 스폰서가 급한 불을 꺼준다.** 공짜는 아니고
  직원 전체의 의욕이 깎인다. 그 전에 **계약 일감**을 받는 편이 싸게 먹힌다.

## 회의실 회의 🗣

개발이 시작될 때, 그리고 아이디어 카드가 나올 때마다 배정된 팀원이
**자리에서 일어나 A\* 경로를 따라 회의실까지 걸어가** 원탁에 앉는다.
직군과 회의 단계에 맞는 대사가 말풍선으로 오가고, 카메라가 회의실을
잡았다가 원래 시점으로 돌아온다. 회의가 끝나야 카드 선택창이 뜬다.

연출을 끄고 싶으면 **회사 탭 → 설정 → 회의 연출 보기**.

## 개발 = 보스전 👾

개발 버튼을 누르면 **아이디어가 형체를 갖고 사무실 한복판에 뜬다.**
장르마다 다른 몬스터가 나오고 (퍼즐 골렘, 대마왕 시나리오, 서버 리바이어던…),
HP가 있고, 페이즈가 있고, 반격을 한다.

| 요소 | 내용 |
|---|---|
| **페이즈** | HP 66% · 33% 에서 아이디어가 형태를 바꾼다. 단단해지지만 전환 직후 **2턴 동안 약점이 드러나 데미지 ×1.45** |
| **반격** | 4턴마다 사양 변경 · 버그 폭주 · 납기 압박 · 서버 다운 중 하나. 팀원의 **체력**을 깎고 완성작에 **버그**를 남긴다 |
| **집중 개발** | 스태미나를 2 더 쓰고 타이밍 바를 멈춘다. 금색 칸 한복판이면 **×2.2**, 빗나가면 ×0.75 — 실제로 손해가 나므로 누를 때 긴장한다 |
| **진행 패널** | 화면 오른쪽에 **재미 점수 · 다섯 품질 축 · 예상 버그 · 번뜩임 · 팀 체력**이 실시간으로 뜬다. 완성 계산과 **같은 곡선**을 쓰므로 여기 뜬 숫자가 그대로 결과가 된다 |

## 직원 체력과 상점 🍜

직원에게 **체력**이 생겼다. 개발 턴마다 줄고, 보스의 반격이 크게 깎는다.
체력이 40% 아래로 떨어지면 '지침', 0이면 '탈진' — 데미지와 품질이 같이
떨어진다. 다만 **0이 되어도 힘이 0이 되지는 않는다.** 굶은 팀은 느려질
뿐 멈추지 않는다.

회복은 세 갈래다: **다음 주 휴식**, **상점의 음식**, 그리고 배틀 화면
아래의 **도우미 트레이**(가방 속 음식을 그 자리에서 가장 지친 사람에게).

**스태미나도 마찬가지로 하루를 넘겨야만 차지 않는다.** 상점의 캔커피 ·
에너지 드링크 · 스페셜티 원두가 즉시 채워주고, **야근**(주 1회)은 돈과
직원의 체력·의욕을 스태미나로 바꾼다.

### 장비 — 직원마다 특색이 생기는 자리

상점의 **장비**는 가방을 거쳐 직원에게 장착된다 (한 사람당 3칸).
장비는 두 가지를 동시에 올린다.

- 그 사람의 **능력치** (→ 배틀 데미지가 오른다)
- 그 사람이 밀어 올리는 **품질 축의 상승폭**

즉 사운드 담당에게 **🎹 업라이트 피아노**를 사주면 사운드 수치만 오르는 게
아니라, 그 사람이 만드는 게임의 **화제성 +13% · 임팩트 +11%** 가 실제
완성 점수에 붙는다. 기획자에게는 아이디어 노트, 프로그래머에게는 기계식
키보드, 디자이너에게는 액정 타블렛, 네트워커에게는 서버 랙.

## 도감 📖

무엇을 모으는 게임인지 한 화면에서 보인다. **잡은 아이디어**(장르별 16종,
격파 횟수·최고 점수·최단 턴), **써본 소재**, **사본 아이템**, **거쳐간
직업**, 그리고 **발견한 장르×소재 조합** — 전부 합쳐 344칸이다.

## 그 밖의 시스템

| 시스템 | 무엇을 결정하나 |
|---|---|
| **직원 특성** | 일벌레·완벽주의·번뜩임·베테랑·분위기 메이커 등 10종. 한 사람이 1~2개. 데미지·품질·버그·급여·팬을 각각 다르게 건드리므로 "누구를 이 프로젝트에 넣나"가 실제 선택이 된다 |
| **연구 포인트** | 개발과 계약이 벌어들이는 장기 화폐. 기획서 등급 · 팀 데미지 · 버그 · 초기 유저 · 이탈률을 **영구히** 올린다 |
| **홍보** | 출시 직전에 개발비의 0.35~2.2배를 태워 초기 유저를 최대 2.2배로. 품질로 이기느냐 돈으로 이기느냐 |
| **계약 일감** | 스태미나를 팔아 확실한 현금과 연구 포인트를 받는다. 파산 방지선이자 초반 자금줄 |
| **시장 유행** | 분기마다 장르 하나·소재 하나가 뜬다. 맞으면 ×1.55, 어긋난 장르는 ×0.78 — 아는 조합이 항상 정답은 아니게 만드는 장치 |
| **조합 도감** | 발견한 장르×소재 조합과 그때의 최고 점수가 기록된다 (도감 탭) |
| **화면 밝기** | 회사 탭 → 설정에서 4단계. 노출·앰비언트·천장 조명·비네트를 한 손잡이로 같이 움직인다. 기본값은 '밝게' — 폰을 밖에서 보면 이전 기본값은 거의 안 보였다 |
| **사무실 확장** | 랭크가 층을 **허가**하고 돈이 층을 **산다**. 산 층은 매주 유지비가 나가고, 1층(창고방)만 공짜다 |

## 모바일

세로 390px 안에 사무실과 패널이 함께 들어가야 하므로 레이아웃 전체가
가로 기준으로 짜여 있다.

- **패널은 접힌 채로 시작한다.** ☰ 로 슬라이드해 열고, 열면 배틀 바가
  옆으로 비켜난다. 폭이 900px 이상이면 접는 버튼 자체가 사라진다.
- **안전 영역**(`env(safe-area-inset-*)`)을 모든 고정 요소에 적용한다.
  가로에서는 노치가 화면의 한쪽 변을 통째로 먹는다.
- **`100vh` 를 쓰지 않는다.** 모바일에서 `100vh` 는 "주소창이 숨겨졌을 때의
  높이"라 대부분의 시간 동안 틀리다. `visualViewport` 를 추적해 `--vh` 로
  넣는다.
- **품질 티어**를 GPU 문자열·코어 수·메모리로 판정해 그림자 해상도(1024–2048),
  DPR 상한(1.0–2.0), 블룸 단계(3–5)를 조절한다. `?q=low|mid|high` 로 강제 가능.
  DPR 상한이 가장 큰 레버다 — 3배 화면은 1배의 9배 픽셀이고, 팔 길이에서는
  대부분 구분하지 못한다.
- 풀 투 리프레시, 더블탭 줌, 롱프레스 선택, iOS 고무줄 스크롤을 모두 막는다.
- 첫 터치에서 전체화면과 가로 잠금을 시도한다 (거부돼도 게임은 그대로 돈다).

## 배포

Vercel 정적 배포. 빌드 스텝이 없으므로 설정도 사실상 없다.

```bash
npx vercel --prod
```

`vercel.json` 은 캐시 헤더만 정한다 — `sw.js` 와 `src/` 는 매번 재검증,
아이콘은 1년 불변. 서비스 워커가 실제 캐싱을 담당하므로 HTTP 캐시를
길게 잡으면 업데이트가 전파되지 않는다.

`sw.js` 의 `ASSETS` 목록은 `src/` 와 `icons/` 를 훑어 생성한 것이다.
파일을 추가하면 목록과 `CACHE` 버전을 함께 갱신해야 한다.

## 구조

```
src/
  core/     math · gl · color · meshbuilder · bake      순수 렌더 유틸
  render/   shaders · renderer · camera                 PBR 파이프라인
  char/     rig · poses                                 16본 스켈레톤
  world/    palette · props · office                    지오메트리만
            agents                                      직원 상태 기계 · 길찾기
  game/     data · state · staff · project · economy    순수 시뮬레이션
            dialogue                                    회의 대사 (한국어)
  ui/       hud · device · style.css                    DOM 오버레이
  main.js                                               셋을 묶는다
```

경계가 분명하다. `game/` 은 WebGL을 모르고 (그래서 브라우저 없이 밸런스를
돌려볼 수 있다), `world/` 는 게임 규칙을 모르고, `core/` 는 둘 다 모른다.

## 그래픽

텍스처 파일이 하나도 없다. 모든 표면은 프래그먼트 셰이더 안의 **프로시저럴
머티리얼** 16종이다 — 카펫 섬유, 나뭇결, 브러시드 메탈, 직물 조직, 아크릴
천장타일, 피부, 머리카락, 그리고 모니터마다 다른 살아있는 화면.

파이프라인:

```
그림자 뎁스 (2048, 12탭 포아송 PCF, 슬로프 바이어스)
   ↓
HDR 씬 (RGBA16F, Cook-Torrance GGX, 표면 그래디언트 범프, 해석적 하늘 IBL)
   ↓
브라이트 패스 (Karis 평균) → 5단 블룸 다운/업샘플
   ↓
컴포짓 (노출 · ACES · 비네트 · 그레인 · 색수차) → FXAA → 캔버스
```

돌하우스 뷰는 두 가지 컷을 쓴다. 카메라와 시점 사이에 선 벽은 4×4 오더드
디더로 녹아 사라지고, 보고 있는 층 위쪽은 통째로 잘려나간다.

## 테스트

```bash
node tools/balance.mjs 12345 10   # 밸런스 시뮬레이션 (브라우저 불필요)
node tools/sloppy.mjs             # 최악의 플레이로 파산 방지선 확인
(setsid python3 -m http.server 8123 &)
node tools/probe.mjs              # 부팅 확인
node tools/meeting.mjs            # 회의 연출
node tools/flow.mjs               # 전체 플로우 19개 검사
node tools/battle.mjs             # 보스전·상점·체력·도감·1인칭 19개 검사
```

## 현재 상태

M1 (뼈대) 완료. 렌더러, 3D 오피스, 캐릭터, 개발 배틀, 회의실 연출,
출시·운영, 랭크, 직원 육성·전직·환생·특성, 연구·홍보·계약·유행,
사무실 층 구매, 세이브까지 한 바퀴가 돈다.

여기에 **3D 보스전**(페이즈·반격·약점·집중 개발), **실시간 진행 패널**,
**직원 체력**, **상점과 가방**(음식·음료·장난감·도구·장비), **야근**,
**도감**, **1인칭 걷기 모드**, **화면 밝기 설정**이 올라가 있다.

밸런스는 `game/` 을 Node에서 그대로 돌리는 헤드리스 시뮬레이션으로 잡았다
(10년치 × 5시드, 그리고 아무것도 안 하는 최악의 플레이로 파산 여부 확인).
결과 표는 [계획서의 밸런스 절](docs/GAME_DESIGN.md#밸런스-헤드리스-시뮬레이션으로-검증)에 있다.

M2 이후 항목은 [계획서](docs/GAME_DESIGN.md#4-마일스톤) 참고.
