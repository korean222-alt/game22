홈 화면에 추가해 주세요

브라우저 주소창이 화면을 가려서, 홈 화면 앱으로 실행할 때 가장 잘 보입니다. 한 번만 추가하면 다음부터는 앱처럼 바로 열립니다.

  1. 사파리 아래쪽 가운데의 공유 버튼 ⬆ 을 누릅니다.
  2. 메뉴를 내려서 “홈 화면에 추가” 를 누릅니다.
  3. 오른쪽 위 “추가” 를 누르면 끝입니다.
  4. 홈 화면의 아이콘으로 실행하고, 가로로 돌려 주세요.
